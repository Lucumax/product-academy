# Roadmap

Priorities, not promises. Items are ordered by the acquisition → activation funnel they
serve. Milestones are not guarantees — they are the conditions under which we decide the next
move.

## Next up

1. **Merge and ship this sprint** — merge `skills-discoverability-growth-v1`, deploy the
   `/skills/` site, apply repository metadata (About, topics, social preview), and publish
   release `skills-v0.3.0`.
2. **Independent comparative evaluation** — run the 12 eval scenarios with model-only, a
   one-off prompt, this pack, and a competitor pack, scored by 5–10 PM reviewers. This is the
   evidence that decides whether we can claim more than "structurally validated."
3. **First-class templates + worked examples** — turn the pointer-artifacts (evaluation
   contract, grandfathering/reversibility design, corrective pilot specs) into real
   `TEMPLATE.md` + `EXAMPLE.md` per skill.

## Stage 1 — Proof of activation

- [x] Skills publishable/installable (ZIPs, marketplace manifest, `npx skills add` verified)
- [ ] `/skills/` site live and indexed
- [ ] Repository metadata applied (About, topics, social preview)
- [ ] First independent PM feedback recorded
- [ ] Install failures collected and understood

## Stage 2 — Repeatable distribution

- [ ] One or more channels consistently drive qualified visits
- [ ] Installations and stars rise after releases
- [ ] Users return or contribute (issues, discussions, PRs)
- [ ] External references/backlinks appear

## Stage 3 — Compounding ecosystem position

- [ ] Directory visibility (skills.sh, agent-skill directories, awesome lists)
- [ ] Community contributions (skills, examples, fixes)
- [ ] Independent recommendations
- [ ] Steady installation telemetry
- [ ] Credible comparative evidence

## Explicitly not on the roadmap

- CTO curriculum expansion.
- An "AI Solutions Architect" track.
- Adding skills just to increase count.
- Fabricating adoption, benchmarks, or endorsements.

## How to propose an item

Open an issue with the job it serves and the acquisition assumption behind it. Priorities are
revisited each release.
