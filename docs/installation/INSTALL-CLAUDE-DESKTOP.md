# Install with Claude.ai / Claude Desktop

1. Download [`product-academy-skills-all.zip`](https://github.com/Lucumax/product-academy/releases/latest).
2. Unzip it.
3. In Claude.ai or Claude Desktop, upload the skill folders (or a ZIP of the ones you want)
   where your assistant accepts project knowledge / custom instructions.
4. Paste a prompt from [START_HERE.md](../../START_HERE.md), e.g.:

```
Run the synthesize-customer-discovery skill. Input: interview notes [notes].
Five of five said X; usage shows Y. Weight the themes.
```

> Status: **DOCUMENTED_ONLY** — this flow depends on the specific Claude plan's knowledge
> features; confirm with your plan. The ZIP contents themselves are verified to build.
