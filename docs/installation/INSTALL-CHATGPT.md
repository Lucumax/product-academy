# Install with ChatGPT

1. Download [`product-academy-skills-all.zip`](https://github.com/Lucumax/product-academy/releases/latest).
2. Unzip it.
3. Attach the skill folders (or the ZIP) as project knowledge / custom instructions in
   ChatGPT, or paste the relevant `SKILL.md` content into a custom GPT.
4. Paste a prompt from [START_HERE.md](../../START_HERE.md).

The skills are written without runtime-specific templating so the same prompt text works in
ChatGPT, Claude, Codex, Cursor, and OpenCode.
