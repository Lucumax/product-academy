# Tools Library

## Purpose

The Academy tools library provides practical, usable templates for the most common product leadership decisions and deliverables. Unlike Product Forge — which produces full execution artifacts (PRDs, roadmaps, release plans) — the Academy tools focus on the strategic thinking behind those artifacts. Each tool is a structured framework for making a specific type of product decision, not a blank form to fill out.

## How to Use These Tools

1. **Identify the decision type.** What kind of decision are you making? Use the tool index below to find the matching template.
2. **Read the template before you start.** Each template includes purpose, when-to-use guidance, section explanations, a filled example, common mistakes, and framework dependencies. Don't just skip to the blank form.
3. **Adapt, don't adopt.** These templates are starting points. Adapt them to your organization's context, industry, and decision culture. A template used rigidly is worse than no template at all.
4. **Use the example as a calibration target.** The filled examples are realistic but anonymized. Compare your output to the example to calibrate depth and specificity.
5. **Get peer review.** For consequential decisions, have a peer review your tool output before finalizing. The tool structures your thinking — it doesn't guarantee good judgment.

## Relationship to Product Forge

Product Forge (the Academy's execution companion) handles the "what" — the specific artifacts teams produce to ship products. The Academy tools handle the "why" and "whether" — the strategic reasoning that determines what should be built in the first place.

| Product Forge Responsibility | Academy Tool Complement |
|------------------------------|------------------------|
| PRD / Feature Brief | Opportunity Assessment, Build vs. Buy |
| Roadmap | Product Strategy, Resource Allocation Memo |
| OKR Setting | Metrics Tree, Evaluation Contract |
| Launch Plan | Post-Launch Review, Pre-Mortem |
| Architecture Decision Record | Platform vs. Feature, Build vs. Buy |
| Quarterly Business Review | Executive One-Pager, Risk-Adjusted Value Assessment |

Where Academy tools overlap with Product Forge artifacts, the Academy version emphasizes the reasoning behind the artifact, not the artifact format itself.

## Tool Quality Standards

Every tool in this library meets the following standards:

1. **Purpose-driven.** You know within 30 seconds whether this tool applies to your situation.
2. **Section-by-section guidance.** Every section explains what goes there, why it matters, and how to fill it out well.
3. **Filled example.** A realistic, anonymized example shows what "good" looks like.
4. **Common mistakes.** The most frequent errors people make with this tool, so you can avoid them.
5. **Dependencies.** What other frameworks, tools, or inputs this tool depends on.
6. **Not a blank form.** This is a thinking guide, not a template to mindlessly populate.
