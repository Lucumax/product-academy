# Curriculum Map

## Overview

The Product Leadership Academy curriculum is organized into 13 tracks across 4 developmental levels. Each module has defined prerequisites, estimated time commitments, and assessment gates. This map shows the complete hierarchy, dependencies, and learning paths.

---

## Level Structure

| Level | Target Roles | Focus | Estimated Total Time |
|-------|-------------|-------|---------------------|
| **L1: Foundation** | Senior PM | Individual product leadership | 40–60 hours |
| **L2: Advanced** | Principal PM | Multi-team, cross-functional leadership | 50–80 hours |
| **L3: Organizational** | Director | Portfolio and organizational leadership | 60–100 hours |
| **L4: Institutional** | VP/CPO | Company-level product leadership | 80–120 hours |

## Learning Paths by Role

### Senior PM Path
```
00 (Orientation) → 01 (Core Doctrine) → 04 (Archetypes — primary + adjacent)
    → 09 (Tools) → 07.1 (Strategic Cases) → 10.1 (Senior PM Scenarios)
    → Assessment Gate: Senior PM Quality Gate
```

**Key modules:** 01.1, 01.2, 01.3, 01.4, 01.5, 01.6, 01.7, 01.8, 04.0 + primary archetype, 09.1–09.4

**Estimated total:** 60–100 hours (including practice and assessment)

### Principal PM Path
```
Senior PM Path (or equivalent) → 02 (Principal Plus) → 03.1–03.3 (Business + GTM foundations)
    → 04 (Archetypes — additional 2+ archetypes) → 07.2, 07.5 (Execution + Conflict Cases)
    → 10.2 (Principal PM Scenarios) → Assessment Gate: Principal PM Quality Gate
```

**Key modules:** 02.1–02.8, 03.1, 03.2, 03.3, 04 (additional archetypes), 07.2, 07.5, 10.2

**Estimated total:** 110–180 hours (cumulative with Senior PM path)

### Director / VP Path
```
Principal PM Path (or equivalent) → 03.4–03.7 (Advanced Business + GTM)
    → 05 (AI PM — select modules) → 06 (Industry Overlays — relevant overlays)
    → 08 (Contradictions) → 07.3, 07.4 (Organizational + Institutional Cases)
    → 10.3, 10.6 (Director + Org Change Scenarios) → Assessment Gate: Director Quality Gate
```

**Key modules:** 03.4, 03.5, 03.6, 03.7, 05.6, 05.7, 06 (relevant overlays), 08.1–08.10, 07.3, 07.4, 10.3, 10.6

**Estimated total:** 180–280 hours (cumulative with Principal PM path)

### CPO Path
```
Director/VP Path (or equivalent) → 03.7 (Board Narrative — full depth)
    → 05.4, 05.5, 05.7 (AI Strategy) → 06 (Industry Overlays — all)
    → 08 (Contradictions — full depth) → 07.4, 07.6 (Institutional + Failure Cases)
    → 10.4, 10.5, 10.8 (CPO + Crisis + Ethics Scenarios)
    → Assessment Gate: CPO Quality Gate
```

**Key modules:** All remaining modules not completed in previous paths

**Estimated total:** 260–400 hours (cumulative with Director/VP path)

## Using This Map

1. **Identify your starting level** based on current role and honest self-assessment (not title)
2. **Follow your role's learning path** in Track 11 for the recommended sequence
3. **Use the module IDs** to navigate the repository — each module directory uses the same ID system
4. **Complete assessment gates** before progressing to the next level — they are diagnostic, not punitive
5. **Use the Personal Lab (Track 12)** continuously throughout your development

The curriculum is designed to be completed in sequence within each level, with levels building cumulatively. Skipping modules because you "already know it" is the most common cause of gaps that surface painfully later.
